# Archive

This directory preserves material that is not part of either maintained
pipeline.

- `R/` - superseded helper modules.
- `scripts/` - historical one-off analyses and plotting scripts.
- `legacy-analysis/` - older exploratory post-scAbsolute/post-scUnique code.
- `sample-manifests/` - previous project-specific manifests and summary tables.
- `project-notes/` - historical development notes.
- `generated/` - previously tracked generated artifacts.

Archived code may contain old absolute paths, assumptions, or dependencies. It
is retained for reference and is not exercised by the current pipeline tests.
